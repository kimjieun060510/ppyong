# 공원 두더지 팡!

공원 배경에서 무작위로 열린 구멍으로 두더지가 나오고, 사람이 뛰어다니며 잡는 웹 게임입니다. 두더지를 잡을 때마다 코인을 모아 뿅망치를 업그레이드할 수 있습니다. 컴퓨터와 휴대폰·태블릿에서 플레이할 수 있습니다.

## 플레이 방법

1. `index.html`을 브라우저에서 엽니다.
2. **게임 시작**을 누릅니다.
3. 구멍에서 두더지가 나오면 가까이 달려가 잡습니다.
4. 모은 코인으로 상점에서 뿅망치 범위·속도, 달리기, 코인 보너스, 광역 타격을 올립니다.

### 조작

| 동작 | 컴퓨터 | 휴대폰 |
| --- | --- | --- |
| 이동 | WASD 또는 방향키 | 왼쪽 **동그라미를 끌어서** |
| 뿅망치 | 스페이스 | 오른쪽 **뿅** 버튼 |
| 상점 | `E` 또는 상점 버튼 | 상점 버튼 |

두더지 근처로 달려가면 자동으로도 잡힙니다.

## 게임 규칙

- 구멍 위치는 매 판 무작위로 배치됩니다.
- 두더지는 무작위로 올라오며, 구멍에 **약 3~4초** 머무릅니다. 가끔 **황금 두더지**가 나와 코인을 더 줍니다.
- 한 라운드는 40초, 총 6라운드입니다. 라운드가 끝나면 상점에서 업그레이드할 수 있습니다.
- 연못에 들어가면 풍덩 빠지고, 5초 카운트다운 동안 움직일 수 없습니다. 그다음 안전한 곳으로 나옵니다.

## 로컬에서 열기

파일을 더블클릭해도 되고, 아래처럼 작은 서버를 켜도 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속하세요.
