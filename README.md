# 뿅

뿅망치를 들고 뛰어다니며 두더지를 잡는 웹 게임입니다. 첫 배경은 공원이고, 구멍을 열 때마다 두더지나 다른 동물이 나옵니다. 잡은 코인으로 뿅망치를 업그레이드할 수 있습니다. 컴퓨터와 휴대폰·태블릿에서 플레이할 수 있습니다.

## 플레이 방법

1. `index.html`을 브라우저에서 엽니다.
2. **여자/남자**와 **옷**을 고른 뒤 **게임 시작**을 누릅니다.
3. 구멍에서 두더지가 나오면 가까이 달려가 **스페이스**나 **뿅망치 버튼**으로 잡습니다.
4. 모은 코인으로 상점에서 뿅망치 범위·속도, 달리기, 코인 보너스, 광역 타격을 올립니다. 상점에서는 코디도 갈아입을 수 있습니다.

### 조작

| 동작 | 컴퓨터 | 휴대폰 |
| --- | --- | --- |
| 이동 | WASD 또는 방향키 | 왼쪽 **동그라미를 끌어서** |
| 뿅망치 | 스페이스 | 오른쪽 **뿅** 버튼 |
| 상점 | `E` 또는 상점 버튼 | 상점 버튼 |

가까이 가기만 해서는 잡히지 않고, 뿅망치를 눌러야 맞습니다.

## 게임 규칙

- 공원은 넓고 구멍이 많아서, 구멍 사이를 뛰어다니며 잡습니다.
- 두더지는 굴에서 자연스럽게 고개를 내밀며, **약 3~4초** 머무릅니다. 황금 두더지는 코인을 더 줍니다.
- 가끔 다른 동물이 나옵니다. **스컹크** 방귀는 게임 오버, **토끼**가 뿌린 당근은 3초 동안 캐릭터만 멈추게 하고, **너구리**는 할퀴어 코인을 빼앗습니다.
- 한 라운드는 40초, 총 6라운드입니다. 라운드가 끝나면 상점에서 업그레이드할 수 있습니다.
- 연못에 들어가면 허우적거리며 5초 동안 못 움직입니다. 제한 시간은 그대로 줄어듭니다.

## 로컬에서 열기

파일을 더블클릭해도 되고, 아래처럼 작은 서버를 켜도 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속하세요.
