# 뿅

뿅망치를 들고 뛰어다니며 두더지를 잡는 웹 게임입니다. 첫 배경은 공원이고, 구멍을 열 때마다 두더지나 다른 동물이 나옵니다. 잡은 코인으로 뿅망치를 업그레이드할 수 있습니다. 지금은 iOS 출시를 기준으로 Apple ID 로그인을 씁니다.

## 플레이 방법

1. `index.html`을 브라우저에서 엽니다.
2. **Apple로 로그인**을 눌러 계정을 만듭니다. (로컬 미리보기에서는 Apple 설정이 없어도 계정이 만들어집니다.)
3. 프로필에서 **캐릭터 꾸미기**(성별·코디·뿅망치)와 **스테이지**(공원 낮/노을/밤)를 고릅니다. 로그아웃도 여기서 합니다.
4. 다음 단계는 한 판 점수가 기준을 넘으면 열립니다. 단계가 오를수록 구멍이 더 자주 열리고 동물이 더 빨리 들어갑니다.
5. **게임 시작**을 누르면 동물 설명이 뜬 뒤 공원이 시작됩니다.
6. 구멍에서 두더지가 나오면 가까이 달려가 **스페이스**나 **뿅망치 버튼**으로 잡습니다.
7. 한 판이 끝나면 점수가 계정 코인으로 바뀝니다. 프로필에서 특별한 옷·연못 노·배드민턴 채를 살 수 있습니다. 기본 코디는 무료입니다.
8. 이번 판 상점은 범위·속도 같은 업그레이드만 합니다.

### 조작

| 동작 | 컴퓨터 | 휴대폰 |
| --- | --- | --- |
| 이동 | WASD 또는 방향키 | 왼쪽 **동그라미를 끌어서** |
| 뿅망치 | 스페이스 | 오른쪽 **뿅** 버튼 |
| 상점 | `E` 또는 상점 버튼 | 상점 버튼 |

가까이 가기만 해서는 잡히지 않고, 뿅망치를 눌러야 맞습니다.

## 게임 규칙

- 공원은 넓고 구멍이 많아서, 구멍 사이를 뛰어다니며 잡습니다.
- 두더지는 굴에서 고개를 내밉니다. 낮에는 조금 오래 나와 있고, 밤에는 훨씬 빨리 들어갑니다. 황금 두더지는 점수를 더 줍니다.
- 가끔 다른 동물이 나옵니다. **스컹크** 방귀는 게임 오버, **토끼**가 뿌린 당근은 3초 동안 캐릭터만 멈추게 하고, **너구리**는 할퀴어 코인을 빼앗습니다.
- 한 라운드는 40초, 총 6라운드입니다. 라운드가 끝나면 상점에서 업그레이드할 수 있습니다.
- 맵은 같은 공원이고, **낮 → 노을 → 밤**으로 단계만 바뀝니다. 밤으로 갈수록 구멍이 더 자주 열리고, 동물은 더 빨리 들어갑니다.
- 한 판 점수 4점당 계정 코인 1개가 쌓입니다. 노을은 90점, 밤은 160점이 있으면 해금됩니다.
- 연못에 들어가면 허우적거리며 5초 동안 못 움직입니다. 제한 시간은 그대로 줄어듭니다.

## Apple ID 로그인 (App Store)

실제 Sign in with Apple을 쓰려면 Apple Developer에서 Services ID를 만들고, `game.js`의 `APPLE_CLIENT_ID`에 넣으세요. Return URL은 게임이 열리는 HTTPS 주소와 같아야 합니다. 값이 비어 있으면 미리보기용 로컬 계정으로 진행됩니다. 프로필은 계정마다 `localStorage`에 저장됩니다.

## 로컬에서 열기

파일을 더블클릭해도 되고, 아래처럼 작은 서버를 켜도 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속하세요.
