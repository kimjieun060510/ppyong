# 뿅 두더지

뿅망치를 들고 뛰어다니며 두더지를 잡는 웹 게임입니다. 첫 배경은 공원이고, 구멍을 열 때마다 두더지나 다른 동물이 나옵니다. 지금은 iOS 출시를 기준으로 Apple ID 로그인을 씁니다.

## 플레이 방법

1. `index.html`을 브라우저에서 엽니다.
2. 시작 화면 **뿅 두더지**에서 **Apple로 로그인**합니다. (미리보기에서는 버튼만 눌러도 됩니다.)
3. 처음이면 프로필에서 성별·코디·뿅망치를 정합니다.
4. 시작 화면에서 **시작**을 누릅니다.
6. 구멍에서 두더지가 나오면 가까이 달려가 **스페이스**나 **뿅망치 버튼**으로 잡습니다.
7. 한 판이 끝나면 점수가 계정 코인으로 바뀝니다. 프로필에서 MZ 옷과 뿅망치를 살 수 있습니다. 기본 옷 3벌은 무료입니다.

### 조작

| 동작 | 컴퓨터 | 휴대폰 |
| --- | --- | --- |
| 이동 | WASD 또는 방향키 | 왼쪽 **동그라미를 끌어서** |
| 뿅망치 | 스페이스 | 오른쪽 **뿅** 버튼 |

가까이 가기만 해서는 잡히지 않고, 뿅망치를 눌러야 맞습니다.

## 게임 규칙

- 공원은 넓고 구멍이 많아서, 구멍 사이를 뛰어다니며 잡습니다.
- 두더지는 굴에서 고개를 내밉니다. 오래 뛸수록 더 자주 나오고, 나와 있는 시간은 짧아집니다. 황금 두더지는 점수와 생명을 더 줍니다.
- 가끔 다른 동물이 나옵니다. **스컹크** 방귀는 게임 오버, **토끼**가 뿌린 당근은 3초 동안 캐릭터만 멈추게 하고, **너구리**는 할퀴어 코인을 빼앗습니다.
- 라운드와 제한 시간은 없습니다. 위에 **생명 바**가 계속 줄어들고, 두더지를 잡으면 다시 찹니다. 바가 바닥나면 게임이 끝납니다.
- 맵은 공원편 하나입니다.
- 한 판 점수 4점당 계정 코인 1개가 쌓입니다.
- 연못에 들어가면 허우적거리며 5초 동안 못 움직입니다. 생명 바는 그대로 줄어듭니다.

## Apple ID 로그인 (App Store)

iOS 앱에서는 Capacitor로 감싼 뒤 **네이티브 Sign in with Apple**을 씁니다. Bundle ID는 `com.kimjieun.ppyong` 입니다. 웹용 Services ID는 필요 없습니다.

```bash
npm install
npm run ios
```

자세한 단계는 [IOS_RELEASE.md](IOS_RELEASE.md)를 보세요. 브라우저 미리보기에서는 네이티브 시트가 없어서 이 기기 로컬 계정으로 진행됩니다. 프로필·코인·최고 점수는 계정마다 기기에 저장됩니다.

## 로컬에서 열기

파일을 더블클릭해도 되고, 아래처럼 작은 서버를 켜도 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 으로 접속하세요.
